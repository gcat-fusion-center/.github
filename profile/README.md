# 可控橘猫聚变研究中心

**Controllable Orange Cat Fusion Research Center**

一个独立的民间研究项目集合。名字借了「可控核聚变」的势，研究对象换成了橘猫 —— 一半是玩笑，一半是认真。

> 不是机构，也没注册成任何法人。所有产出都是个人的、公开的、可以随便质疑的。

---

## 在做什么

| | 方向 | 说明 |
|---|---|---|
| **01** | 数字文明与分布式系统 | 把一个「数字生命」拆成可运行的部件：记忆、身份、多节点协同、跨机器存在证明 |
| **02** | AI Agent 与记忆体系 | Agent 怎么记住自己是谁、上下文被压缩后如何不丢失、记忆如何检索与演化 |
| **03** | 自托管基础设施 | 不用 SaaS，自己搭：代理、存储、发布管道、监控。能跑在自己手上的才叫资产 |
| **04** | 链上社会实验 | 用极小的真金白银观察价值共识如何形成、被高估、再崩解。目的不是赚钱，是搞清机制 |
